# 🎀 Phoebe Desktop Pet · 菲比桌面宠物

> *Wuthering Waves* Phoebe as your desktop companion — entirely generated by AI.
> 《鸣潮》菲比化身桌面精灵，全程 AI 生成。

A frameless, transparent PyQt5 desktop pet. She wanders, follows your mouse, lounges on window edges, and can have her hat knocked off. **All code and assets generated through AI collaboration.**

逐像素透明的 PyQt5 桌面宠物。她会随机漫游、跟随鼠标、悠闲坐在窗口上沿、被打飞帽子……**全部代码与素材均由 AI 协作生成。**

## ✨ Features · 功能特性

| Feature 功能 | Description 说明 |
|---|---|
| 🚶 **Random Roaming** 随机漫游 | Walks to random screen positions with natural height changes. 走到屏幕随机位置，高度随上下坡自然变化。 |
| 🖱️ **Follow Mouse** 跟随鼠标 | Walks/runs toward cursor; turns to face you when close. 朝光标走/跑，靠近后转身面向你。 |
| 🪟 **Window Lounging** 悠闲坐窗 | Drag onto any window's top edge — she sits there, tracking window movement. 拖到任意窗口上沿即坐下，窗口移动时跟随。 |
| 🎩 **Hat Physics** 帽子物理 | Triple-click knocks hat off (parabolic trajectory); drag it back to re-attach. 三连击打飞帽子（抛物线掉落），拖回即可戴回。 |
| 🎤 **Vocal Interactions** 声音互动 | Random chirps, double-click barking, idle talking with gestures (hand raise, hop). 随机叫声、双击叫、站立说话配举手/小跳动作。 |
| 📋 **Context Menu** 右键菜单 | Walk, run, spin, sit, size control, quiet mode, voice frequency slider. 散步/走路/跑步/转圈/坐下/大小/安静一点/叫声频率。 |
| 🔍 **Transparent & Always-on-Top** 透明置顶 | Pure pixel transparency, zero window chrome. 逐像素透明，无边框无背景。 |

## 🎮 Interactions · 交互操作

| Action 操作 | Effect 效果 |
|---|---|
| **Drag** 左键拖拽 | Grab Phoebe anywhere; drop on a window edge → lounge. 抓住菲比随意摆放；拖到窗口上沿 → 悠闲坐窗。 |
| **Double-click** 双击 | Random bark (rare "Fei Ba Jiu Bi" Easter egg). 随机叫一声（小概率"菲八啾比"彩蛋）。 |
| **Triple-click** 三连击 | Knock hat off (front-facing / sitting only). 打飞帽子（仅正面/坐下时生效）。 |
| **Drag hat back** 拖帽子回 | Re-attach hat early. 帽子飞出后拖回菲比头上提前戴回。 |
| **Right-click** 右键 | Full menu: movement, poses, direction, follow mouse, hat toggle, settings. 完整菜单：运动/动作/方向/跟随鼠标/帽子切换/设置。 |
