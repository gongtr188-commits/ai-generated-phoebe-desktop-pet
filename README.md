## ✨ Features · 功能特性

### 🚶 Random Roaming · 随机漫游

Phoebe autonomously walks to random positions on your screen. Her height changes naturally with each waypoint — like walking up and down gentle slopes. She'll occasionally stop midway and choose a new direction. Each walk cycle triggers a cute chirp.

菲比自主在屏幕上随机散步，高度随目标点自然起伏，像在缓坡上行走。偶尔中途换方向，每次起步都有概率"啾"一声。

### 🖱️ Follow Mouse · 跟随鼠标

Activate via right-click menu. Phoebe walks toward your cursor at a distance, runs when far away, and gracefully slows down as she approaches to avoid overshooting. A **4-layer anti-oscillation system** prevents jitter: proportional speed damping, dead-zone thresholds, horizontal-axis locking at close range, and pure-vertical mode when aligned.

右键菜单开启。远处的光标 → 跑步追，近了 → 走路，更近 → 比例降速防过冲，到面前 → 转身面向你。**四层防抖系统**：比例降速 + 死区阈值 + 横轴接近锁死 + 纵轴纯直移动。

### 🪟 Window Lounging · 悠闲坐窗

Drag Phoebe onto the **top edge of any window** (browser, IDE, explorer…) and she'll sit there, swinging her legs. She tracks the window's movement in real time — if you move, minimize, or maximize the window, she follows or jumps down gracefully. DPI-aware across mixed-resolution multi-monitor setups.

把菲比拖到**任意窗口上沿**（浏览器、IDE、资源管理器……），她就坐在窗口上沿晃腿。窗口移动/最小化/最大化时，她实时跟随或自动跳下。跨混合 DPI 多显示器也无缝适配。

### 🎩 Hat Physics · 帽子物理

**Triple-click** Phoebe (while front-facing or sitting) to knock her hat off. The hat launches in a **realistic parabolic trajectory** with horizontal offset constraints, then fades away after ~38 seconds. **Drag the hat back** onto her head to re-attach it early. Follow-mouse mode auto-restores the hat.

**三连击**正面/坐着的菲比 → 帽子沿**抛物线物理轨迹**飞出，约 38 秒后自动消失。**拖帽子回她头上**可以提前戴回。跟随鼠标模式下自动禁止无帽状态。

- **Double-click bark**: Random voice line; rare "Fei Ba Jiu Bi" Easter egg

## 🐛 FAQ · 常见问题

<details>
<summary><b>Q: Phoebe doesn't appear after launch · 启动后看不到菲比？</b></summary>

**A:** Check your system tray — she might be off-screen if you have multiple monitors. Try right-clicking the taskbar > "Cascade windows" to bring all windows into view. Alternatively, end the `python.exe` (or `PhoebeDesktopPet_v4.exe`) process from Task Manager and re-launch.

检查是否在多显示器扩展屏外。任务管理器结束进程后重试。
</details>

<details>
<summary><b>Q: No sound / 没有声音？</b></summary>

**A:** Ensure your system volume isn't muted. In Quiet Mode volume is intentionally low — toggle it off from the right-click menu. If using source code, verify PyQt5 multimedia support: `pip install PyQt5`.

确认系统音量未静音。"安静一点"模式音量故意调低，右键关掉试试。源码运行的话确认 PyQt5 多媒体支持正常。
</details>

<details>
<summary><b>Q: Can't knock hat off · 打不飞帽子？</b></summary>

**A:** Triple-click only works when Phoebe is **front-facing standing** or **sitting**, and NOT in follow-mouse mode. Clicks must be within 0.5s of each other.

三连击仅对**正面站立**或**坐着**的状态生效，跟随鼠标模式下禁用。单击间隔需在 0.5 秒内。
</details>

<details>
<summary><b>Q: How to hide Phoebe temporarily · 怎么暂时隐藏？</b></summary>

**A:** Right-click > **Quit**. She'll be back next launch. There's no minimize-to-tray currently — quit and re-launch is instant.

右键 → 退出即可。目前没有最小化到托盘功能，退出再启动也很快。
</details>

<details>
<summary><b>Q: Antivirus flags the EXE · 杀毒软件报毒？</b></summary>

**A:** The EXE is built with PyInstaller, which bundles a Python interpreter — some antivirus heuristics flag this as suspicious. It's a false positive. You can verify by running from source instead.

EXE 是 PyInstaller 打包的，内嵌 Python 解释器，部分杀软的启发式扫描会误报。不放心的可以下载源码包用 Python 直接跑。
</details>
