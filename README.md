# Phoebe Desktop Pet (AI-Generated)

> *Wuthering Waves* Phoebe as your desktop companion — entirely generated by AI.

A frameless, transparent PyQt5 desktop pet featuring Phoebe from *Wuthering Waves*. She wanders your screen, follows your mouse, lounges on window edges, and can have her hat knocked off. **All code and assets were generated through AI collaboration.**

## Features

- **Random Roaming** — walks to random screen positions with natural height changes
- **Follow Mouse** — walks/runs toward cursor, turns to face you when close
- **Window Lounging** — drag her onto any window's top edge and she'll sit there, tracking window movement
- **Hat Physics** — triple-click to knock her hat off (parabolic trajectory); drag it back to re-attach
- **Vocal Interactions** — random chirps, double-click barking, idle talking with gesture animations (hand raise, hop)
- **Context Menu** — walk, run, spin, sit, size control, quiet mode, and more
- **Transparent & Always-on-Top** — pure pixel transparency, zero window chrome

## Interactions

| Action | Effect |
|---|---|
| **Drag** | Grab Phoebe anywhere; drop on a window edge to lounge |
| **Double-click** | Random bark (rare "Fei Ba Jiu Bi" Easter egg) |
| **Triple-click** | Knock hat off (front-facing / sitting only) |
| **Drag hat back** | Re-attach hat early |
| **Right-click** | Full menu: movement, poses, direction, follow mouse, hat toggle, settings |

## Quick Start

### Option 1: Standalone EXE (No Python Required)
Download `PhoebeDesktopPet_v4.exe` from [Releases](https://github.com/gongtr188-commits/ai-generated-phoebe-desktop-pet/releases) and double-click.

### Option 2: Python Source
```bash
pip install PyQt5
python phoebe_pet.py
```
Or download `PhoebeDesktopPet_v4.zip` from [Releases](https://github.com/gongtr188-commits/ai-generated-phoebe-desktop-pet/releases) and run `start_phoebe.bat`.

## Project Structure

```
phoebe_pet.py       # Main application (PyQt5 state machine)
start_phoebe.bat    # Quick launch script
assets/poses/       # Static pose PNGs
assets/anim/        # Animation frames (walk, run, spin, hop, lounge)
assets/sounds/      # Voice clips (mp3)
tools/matting.py    # Flood-fill image matting
tools/pet_proc.py   # Process manager (find/kill)
tools/pack_release.py # Release packager
README.md
```

## Tech Stack

- **Python 3.12** + **PyQt5** (GUI, animation, sound)
- **Win32 API** (window enumeration for lounge, DPI-aware positioning)
- **State machine** with 9 states: idle, walk, run, turn, spin, hop, sit, lounge, drag
